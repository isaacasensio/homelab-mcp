Privacy policy

homelab-mcp · Last updated 11 October 2026

homelab-mcp is a personal tool. It is used only by its author, to access their own Google account. It is not offered to the public.

Who this policy covers

This policy explains what Google user data homelab-mcp accesses, how it is used, stored and protected, and how it can be deleted. The only user is the app's author, accessing their own Google account.

Data accessed

With the user's consent, homelab-mcp requests two read-only Google permissions:

  • Gmail (gmail.readonly): message ID, subject, sender, date and message body, for messages in the inbox or matching a search.
  • Google Calendar (calendar.readonly): event ID, title, start and end time, location and description, for upcoming events.

homelab-mcp cannot send, modify or delete email or calendar events. It does not access contacts, Drive files or any other Google data.

How data is used

Data is fetched from Google only when the user asks their AI assistant a question that needs it, and is returned only to that assistant so it can answer the user. It is not used for advertising, profiling, analytics, or training AI or machine-learning models.

Storage and retention

Email and calendar content is not stored, cached or logged. It exists only in memory while a request is being answered.

The only data homelab-mcp keeps is the Google OAuth token that lets it act on the user's behalf. It is kept on the user's own private server until access is revoked.

Security

homelab-mcp runs on a private home network and is not reachable from the internet. Every request must include a secret API key. Connections use HTTPS, and Google data is requested over Google's encrypted APIs.

Sharing

No data is sold, rented, or shared with or transferred to any third party.

Google API Services User Data Policy

homelab-mcp's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

Access can be revoked at any time at myaccount.google.com/permissions. Revoking access invalidates the stored token immediately, and the token is then deleted from the server. Since no email or calendar content is stored, nothing else needs to be deleted.

Changes to this policy

Any changes will be published on this page, with the date above updated.
