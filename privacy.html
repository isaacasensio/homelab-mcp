Privacy policy

homelab-mcp · Last updated 11 October 2026

homelab-mcp is a personal tool. It is used only by its author, to access their own Google account. It is not offered to the public.

Data accessed

With the owner's consent, homelab-mcp reads Gmail messages and Google Calendar events using the read-only scopes gmail.readonly and calendar.readonly. It never modifies, sends, or deletes anything.

How data is used

Email and calendar data is fetched on request and passed only to the owner's own AI assistant to answer the owner's questions. It is not used for advertising, profiling, or training models.

Storage

The only thing homelab-mcp stores is the OAuth token for the owner's account, kept on the owner's private server. Email and calendar content is not stored or logged.

Sharing

No data is sold, shared with, or transferred to third parties.

Google API Services User Data Policy

homelab-mcp's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Contact

Questions can be raised via GitHub.
